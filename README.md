# Wedding DJ Planner (test version)

A single-page wedding DJ planner: an event dashboard for the DJ and a planner for each couple. It covers ceremony, cocktail hour, grand entrance, dinner, speeches, formal dances, traditions, music preferences and vendors, and builds a day-of run sheet from the answers.

This test version saves everything in the visitor's own browser (localStorage), so entries are not shared between people or devices. The two couples in it are sample data with made-up details.

Hosted with GitHub Pages from the `main` branch root.
